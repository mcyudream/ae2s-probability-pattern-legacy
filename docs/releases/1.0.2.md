# AE2S Probability Pattern Legacy 1.0.2

修复概率样板、有线编码终端和无线编码终端的中英文物品名称多出 `.name` 的问题。
语言资源清理了与 Minecraft 1.12.2 命名流程冲突的无后缀翻译键，保留正确的 `.name` 键。

客户端验收直接检查三种物品、已编码样板的 `ItemStack.getDisplayName()` 和提示框首行，
覆盖 `en_us`、`zh_cn`，并保留原有终端、合成链、HEI 和 Ponder 验收。
16 项单元测试及正式 Cleanroom 0.4.0 客户端 / 专服 × 有 / 无 Ponder 四组验收均通过。

适用 **Minecraft 1.12.2 / Cleanroom 0.4.0 正式版 / Java 25 / AE2 Supergiant（AE2S）**。
实际验收 AE2S 版本 `1.1.0+a47dfe029`，可选 HEI `4.35.1`、Ponder Legacy `1.4.0`
和 CraftTweaker `4.1.20.698`。

升级时将客户端、服务器的旧版主 JAR 替换为 `ae2s-probability-pattern-legacy-1.0.2.jar`。
Mod ID 和物品注册 ID 保持原值，可继续使用已有物品和存档。
`-sources.jar` 用于查看源码，`-mcp.jar` 用作开发依赖；游戏仅安装主 JAR。

发行附件包含 `SHA256SUMS` 与 `VERIFICATION.json`；可使用
`sha256sum --check SHA256SUMS` 校验下载文件。

安装包 SHA-256：`bc663fffdf69c8433a84fd31f9af8e7de5d0266b3e3985a2b83de47156a044c5`。
