# AE2S Probability Pattern Legacy 1.0.1

首个 Minecraft 1.12.2 / Cleanroom **0.4.0 正式版**发行版本，使用 **Java 25**。

Mod ID：`ae2s-probability-pattern-legacy`。显示名称：`AE2S Probability Pattern Legacy`。

## 功能

- 概率处理样板按成功率、95% / 99% 置信度和实际订单量计算尝试次数，支持每次成功产出多个物品。
- 多层概率合成先扣除已有中间库存；合成 CPU 保存重载后保留订单的缩放用料和供应器派发结果。
- 提供有线、无线概率编码终端，并支持合并到 AE2S 万用终端。
- 可选 HEI / JEI 配方导入及成功率提取。
- 可选中英文 Ponder 演示；已修复百分号导致的 `Format error` 和旁白遮挡。

## 安装

客户端和服务器安装 `ae2s-probability-pattern-legacy-1.0.1.jar`，必装
**Applied Energistics 2 Supergiant（AE2S）**。实际验收版本为 `1.1.0+a47dfe029`，
固定依赖及哈希见仓库 `dependency-lock.json`。本版本不声明兼容原版 AE2 或 AE2UEL。

可选 HEI `4.35.1`。需要演示时安装 **Ponder Legacy 1.4.0** 和
**CraftTweaker 4.1.20.698**。没有 Ponder 时核心功能可独立使用。

`-sources.jar` 是源码包，`-mcp.jar` 是开发依赖；游戏只安装没有这两个后缀的主 JAR。

## 验证

正式 Cleanroom 0.4.0、Java 25、上述固定 AE2S 版本：客户端和专服有 / 无 Ponder
四种组合均通过实际运行验收；16 项单元测试通过。完整证据及中英文演示截图位于仓库
`verification/`，CI 在发布前重跑这些场景。

安装包 SHA-256：

```text
6ef33ddf52f728cc555afc0029bd0b90cd25d1f3263b74365235b5bffe1b3969
```

下载后可用 `sha256sum --check SHA256SUMS` 核对所有发行产物。
置信度是每层概率指标；大订单采用上游正态近似，少产时仍可能需要补足产物或重试。
